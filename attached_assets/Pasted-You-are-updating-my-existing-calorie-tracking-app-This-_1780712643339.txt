1. QUANTITY SUPPORT
   ====================================================

Add a Quantity field when the user creates calorie entries.

Quantity should:

* Default to 1
* Allow decimals, such as 0.5, 1.5, 2.25
* Must be greater than 0
* Multiply the calories for that item

Example:

Food: Quest Bar
Calories each: 180
Quantity: 2

Total calories added:
180 × 2 = 360 calories

Show the math clearly before saving:

“180 calories × 2 = 360 calories”

Apply Quantity to:

* Manual calorie entries
* Regular saved entries
* Meal ingredients
* Meal entries copied from saved meals
* Duplicated entries when reasonable

For existing entries that do not have quantity, treat quantity as 1.

====================================================
2. QUANTITY FOR MEAL INGREDIENTS
================================

Meal Entry ingredients should also support Quantity.

Each ingredient should have:

* Ingredient name
* Input method
* Quantity
* Calories
* Total ingredient calories

Ingredient quantity should allow decimals.

Manual ingredient example:

Ingredient: Egg
Calories each: 70
Quantity: 2

Total:
70 × 2 = 140 calories

Automatic grams ingredient example:

Ingredient: Peanut Butter
Grams eaten: 32g
Serving size: 32g
Calories per serving: 190
Quantity: 1.5

Base calculation:
32 ÷ 32 × 190 = 190 calories

Quantity calculation:
190 × 1.5 = 285 calories

The full meal total should automatically include quantity-adjusted ingredient totals.

3. QUICK ADJUST DIAL ON DASHBOARD
=================================

Add a new Quick Adjust Dial directly near the main calorie circle on the Today dashboard.

Purpose:
The user can quickly add or subtract calories without opening the full entry form.

Dial behavior:

* Range: -1000 to +1000 calories
* Step amount: 5 calories
* Default selected amount: 0
* User can swipe/scroll up and down to change the selected amount
* Must work well on mobile
* Must also work on desktop with mouse/trackpad
* Clearly display the selected amount

Examples:

* +150
* -75
* +500
* -250

Button behavior:
If selected amount is positive:
Button text should be something like:
“Add +150”

If selected amount is negative:
Button text should be something like:
“Apply -75”

If selected amount is 0:
Button should be disabled.

Important:
Do not only use a plus icon, because the dial supports negative values too.

=======================

Example prompt:

Examples:

* Coffee
* Snack
* Correction
* Quick Add

If the user enters a name, save the log entry using that name.
