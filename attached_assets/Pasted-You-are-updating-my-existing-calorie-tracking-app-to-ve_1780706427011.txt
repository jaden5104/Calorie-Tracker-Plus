3. BY GRAMS UPDATE — TWO METHODS
====================================================

The existing “By Grams” feature must remain.

Add two methods/tabs inside By Grams:

A. Grams Eaten
B. Weigh by Container

------------------------------------
A. Grams Eaten
------------------------------------

Keep the existing method.

The user enters:
- Food name
- Grams eaten
- Serving size grams
- Calories per serving

Formula:

grams eaten / serving size grams * calories per serving = calories consumed

Show the math before saving.

Example:

50g eaten ÷ 28g serving × 140 calories = 250 calories

------------------------------------
B. Weigh by Container
------------------------------------

Add a new method called “Weigh by Container.”

Purpose:
The user can weigh the whole container before eating and after eating. The app calculates how much they ate.

The user enters:
- Food name
- Starting container weight in grams
- Ending container weight in grams
- Serving size grams
- Calories per serving

Formula:

starting weight - ending weight = grams eaten

Then:

grams eaten / serving size grams * calories per serving = calories consumed

Example:

Starting weight: 500g
Ending weight: 465g
Amount eaten: 35g
Serving size: 32g
Calories per serving: 190

35 ÷ 32 × 190 = 208 calories

Validation:
- Starting weight must be greater than ending weight.
- Ending weight cannot be negative.
- Serving size must be greater than 0.
- Calories per serving must be greater than 0.

Show the math clearly before the user saves the entry.

Important:
For v1.1, only add Weigh by Container to the main By Grams feature. Do not add Weigh by Container inside Meal Entry yet.
